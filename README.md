# 先验搜索 (PriorSeek / ps)

[![License: MIT OR Apache-2.0](https://img.shields.io/badge/license-MIT%20OR%20Apache-blue.svg)](LICENSE-MIT)
[![ModelScope Artifacts](https://img.shields.io/badge/ModelScope-Artifacts%20Hub-orange.svg)](https://www.modelscope.cn/models/Reasone/priorseek)

**先验搜索 (PriorSeek)** 是一个高性能、严谨可复现的检索算法实验台与先验检索内核。

项目践行第一性原理：**“深度学习内核产出先验因子，极简外壳组织检索执行，外壳零人工超参数”**。
通过将神经网络的语义理解能力前置为离线计算的离散先验因子，在线外壳退化为高度优化的纯 CPU 倒排执行器，兼具深度语义泛化与微秒级响应性能。

## 核心架构：中英双语解耦扩散与纯 CPU 零超参外壳

```text
┌──────────────────────── 离线深度学习内核 (Neural Kernel) ────────────────────────┐
│                                                                                  │
│                        [ 输入查询 / 文档 Token ]                                 │
│                                    │                                             │
│                 ┌──────────────────┴──────────────────┐                          │
│                 ▼                                     ▼                          │
│       ┌───────────────────┐                 ┌───────────────────┐                │
│       │  英文特化扩散网络  │                 │  中文特化扩散网络  │                │
│       │ (SPLADE-EN 30k维) │                 │ (SPLADE-ZH 32k维) │                │
│       └─────────┬─────────┘                 └─────────┬─────────┘                │
│                 │                                     │                          │
│                 └──────────────────┬──────────────────┘                          │
│                                    ▼                                             │
│                   [ 多语言 Token 映射枢纽 (Bilingual Hub) ]                      │
│                   • 概念层对齐：中英跨语言概念无缝投影                           │
│                   • 语法层隔离：同语系内扩散，杜绝跨语言交叉污染                 │
│                                    │                                             │
└────────────────────────────────────┼─────────────────────────────────────────────┘
                                     ▼ 先验因子工件 (sparse.bin / 离散词权向量)
┌──────────────────────── 在线检索外壳 (Pure Rust Shell) ──────────────────────────┐
│                                                                                  │
│   带权倒排索引 (SparseInvertedIndex)                                             │
│   打分公式：score(q, d) = sum_{t in q ∩ d} w(t, q) * w(t, d)                     │
│   • 纯 CPU 运行，零运行时神经网络推理，内存零重分配                              │
│   • 零外壳超参数：无需 BM25 的 k1/b，无需人工阻尼衰减与经验加权                 │
│   • 微秒级响应：中文查询 p50 = 26 μs，英文查询 p50 = 28 μs                      │
│                                                                                  │
└──────────────────────────────────────────────────────────────────────────────────┘
```

## 严谨对账基准 (中英双语真实测试集)

所有指标均在同一测试环境、同一评测口径下严格对拍，结构上杜绝利用金标答案调参（口径源：[`docs/STANDARD.md`](docs/STANDARD.md)）。

### 1. 中文基准 (QBQTC：4,889 篇中文文档 / 3,749 条测试查询)

| 算法 / 适配器 | 架构机制 | hit@1 | hit@3 | hit@10 | MRR@10 | nDCG@10 | CPU p50 延迟 |
|---|---|---:|---:|---:|---:|---:|---:|
| **`bilingual-sparse`** | **中文特化神经稀疏倒排 (零超参)** | 76.23% | **82.72%** | **86.58%** | 0.7991 | **0.8143** | **0.026 ms (26 μs)** |
| `bm25` | 传统中文 Jieba 分词基准 (k1=1.5, b=0.75) | **77.30%** | 82.13% | 84.56% | **0.7995** | 0.8100 | 0.005 ms |

> **中文实测结论**：特化中文神经先验展现出扎实的语义理解力，hit@10 相比 BM25 提升 **+2.02 个百分点**（绝对打捞出 76 条传统词法漏检的困难查询），nDCG@10 达到 **0.8143**，查询延迟仅 26 微秒。

### 2. 英文科学文献基准 (SciFact：5,183 篇科学文献 / 300 条计分查询)

| 算法 / 适配器 | 架构机制 | hit@1 | hit@3 | hit@10 | MRR@10 | nDCG@10 | CPU p50 延迟 |
|---|---|---:|---:|---:|---:|---:|---:|
| **`bilingual-sparse`** | **英文特化神经稀疏倒排 (零超参)** | **58.00%** | 72.33% | 83.33% | **0.6668** | **0.6985** | **0.028 ms (28 μs)** |
| **`neural-hybrid`** | 纯神经双路先验融合 (稀疏 + 稠密向量) | 57.67% | 72.00% | 84.00% | 0.6646 | **0.7017** | 0.631 ms |
| `hybrid-rrf` | 词法先验 + 稠密向量 RRF(60) 融合 | 56.00% | **73.67%** | **85.00%** | 0.6634 | 0.7012 | 0.948 ms |
| `concept-synonym` | 启发式医学同义与词缀对齐外壳 | 55.67% | 72.33% | 82.33% | 0.6470 | 0.6788 | 0.668 ms |
| `bm25` | 传统英文词法基准 (k1=1.5, b=0.75) | 54.33% | 70.33% | 80.33% | 0.6328 | 0.6647 | 0.224 ms |
| `dense` | 单路稠密向量点积 (MiniLM 384维) | 50.33% | 68.33% | 79.33% | 0.6047 | 0.6451 | 0.562 ms |

> **英文实测结论**：单路特化神经稀疏倒排的 nDCG@10 达到 **0.6985**（大幅超越传统 BM25 的 0.6647），首位命中率高达 **58.00%**；查询延迟仅 28 微秒，比双路融合快 30 倍以上。

## 核心设计准则

1. **外壳零超参**：
   - 彻底摒弃脆弱的手工调参常数。词语的语法作用、重要度与同义扩展完全由离线神经网络端到端学习，外壳只做确定性带权倒排点积：`sum(w_q * w_d)`。
2. **语系特化隔离与概念枢纽**：
   - 同一词元的语义扩散只在同语系内完成（中文走中文词表与上下文，英文走英文词表与形态分析），杜绝多语言混合词表的交叉污染；
   - 跨语言关联由轻量多语言概念映射枢纽（`BilingualHub`）处理，职责明确、易于消融与审计。
3. **极速纯 CPU 执行**：
   - 文档与查询的先验因子离线固化为小端二进制工件（`sparse.bin`），在线检索纯由 Rust 在 CPU 上执行，内存占用低，单查询延迟稳定在 20~30 微秒。
4. **防篡改数据契约**：
   - 每个先验工件均附带严格的 `manifest.json` 与 SHA256 校验，从数据源头杜绝非受控漂移。

## 快速上手

### 1. 编译纯 Rust 检索外壳

```bash
git clone https://github.com/vesita/PriorSeek.git
cd PriorSeek
cargo build --release
```

### 2. 获取预构建先验工件（魔搭社区）

预构建的先验权重工件托管于魔搭社区：

```bash
git clone https://www.modelscope.cn/Reasone/priorseek.git /tmp/priorseek-artifacts
mkdir -p data/scifact/artifacts
cp -r /tmp/priorseek-artifacts/* data/scifact/artifacts/
```

### 3. 单查询探针测试

```bash
# 执行单条查询探针调试
cargo run --release --package sl-cli -- probe \
  --dataset scifact \
  --adapter bilingual-sparse \
  --query "Pyridostatin stabilizes the G - quadruplex in the telomeric region." \
  --k 5
```

### 4. 运行全量对比评测

```bash
# 在英文科学语料上对比 BM25 与双语神经稀疏
cargo run --release --package sl-cli -- run \
  --dataset scifact \
  --adapters bm25,bilingual-sparse \
  --k 10
```
