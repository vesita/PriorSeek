# 预注册：神经流匹配/最优传输语义流检索 (Neural Flow Matching，代号 flow-match-v1)

## 1. 核心问题与动机

传统 BM25 无论如何调参，其本质始终是**“孤立词项独立命中求和”**的词袋模型。
它存在致命的物理盲区：
- 无法感知因果流向：把零散提及两个词的无关长文档与严密论证概念转移的精准文档混为一谈；
- 词汇鸿沟死穴：一旦查询意图与文档表达用词不同，词袋得分直接归零。

本实验实现**“神经流匹配 / 最优传输流检索 (Neural Flow Matching)”**：
- **查询意图流 (Query Flow)**：查询是高维语义概念空间中的质量分布 $\mu = \sum_i w_i \delta_{t_i}$；
- **文档论证流 (Document Flow)**：文档是核心论证概念的状态分布 $\nu = \sum_j v_j \delta_{d_j}$；
- **传输代价矩阵 $C(i, j)$**：由内核离线构建的语义距离度量空间给出；
- **最优传输匹配**：计算将查询意图流完整搬运至文档论证流的**最小传输成本（Relaxed Wasserstein / Earth Mover's Distance）**；
- **线上性能保障**：利用松弛最优传输（RWMD），将全局线性规划复杂度降为 $O(|q| \cdot |d_{\text{core}}|)$，纯 CPU 微秒级完成匹配。

## 2. 实验臂设计（单变量对照）

- **基线臂**：`bm25`（传统词袋累加）；
- **词法归并对照**：`concept-bm25`（词法空间形态归并）；
- **测试臂**：`flow-match`（彻底抛弃词袋求和，基于最优传输流最小搬运成本打分）。

## 3. 核心不变量 (Invariants)

1. **传输非负性与度量自洽不变量**：搬运代价 $C(i, j) \ge 0$，当且仅当概念完全相同时 $C(i, i) = 0$。总传输成本越小，相似度得分单调越高。
2. **CPU 极速不变量**：RWMD 外壳算子纯 Rust 原生实现，无动态堆分配，单次文档流匹配计算耗时必须 $< 5$ 微秒。
3. **退化等价性不变量**：当代价矩阵退化为离散狄拉克测度（$C(i,j)=0$ 若 $i=j$ 否则 $1$）时，最优传输流退化为经典交集覆盖匹配。

## 4. 判据与预测

- **判据**：在 $k=10$ 下，nDCG 与 MRR 指标大幅超越传统词袋模型，且查询延迟维持在毫秒级。
- **预测**：在复杂长论述语料（`arguana`）上，流匹配能彻底消灭“词项散落凑数”的假高分文档，命中质量产生质的跃升。
