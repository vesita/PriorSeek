# 预注册：纯 CPU 极速微型神经网络外壳 (CPU Micro-Neural Topological Scorer，代号 neural-topo-v1)

## 1. 核心问题与动机

传统 Dense/Reranker 方案在 CPU 上极其缓慢（动辄数十到数百毫秒），且依赖极其庞大的 Python/C++ 运行时。
本实验探索**“纯 CPU 极速微型神经网络外壳 (Micro-Neural Net on CPU)”**：
- 模型参数量极度紧凑（几十到几百个参数，严格受限于 ≤10k 预算）；
- **纯 Rust 原生实现前向计算**，零外部重型库依赖，利用 CPU L1 Cache 与寄存器快速执行；
- **任务目标**：输入查询词对的相对位置跨距、方向差与先验 Saliency，在线前向预测拓扑匹配置信度；
- **性能红线**：CPU 单查询端到端延迟严格控制在 **< 10ms**。

## 2. 实验臂设计（单变量对照）

- **基线臂**：`bm25`（传统词法基线）；
- **位置约束对照**：`oac`（启发式固定分桶跨距衰减）；
- **测试臂**：`neural-topo`（纯 CPU 微型神经网络在线前向调制结构分）。

## 3. 核心不变量 (Invariants)

1. **CPU 极速不变量**：单查询前向计算总耗时必须在 1ms 以内，端到端延迟 p50 严格 < 10ms。
2. **纯原生零依赖不变量**：前向计算必须由纯 Rust 数组/切片完成，不得链接任何庞大 C++/Python 运行时。
3. **退化等价性不变量**：当网络权重置零或禁用拓扑分支时，外壳严格退化为基础 BM25 分数。

## 4. 判据与预测

- **判据**：在 $k=10$ 下，nDCG 与 MRR 指标相比固定规则显著提升，且查询延迟符合 CPU 生产级约束。
- **预测**：在复杂长文本（`arguana`）上，微型神经网络能更柔和地识别实体就近依存关系，优于粗暴的固定窗口截断。
