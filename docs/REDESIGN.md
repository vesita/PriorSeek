# 重设计方案：以可解释性与泛用性为准绳（不刷分，不拟合权重）

> 依据：本仓 §1–§40 的全部实测（尤其 §13、§18、§23、§33、§36–§40），
> 以及 dsh-pod 记忆召回的 103 条 trace 对照（BM25∩RRF 0.903、OAC∩RRF 0.652）。
> 本文件只写由数据支持的推断；每条推断后面标注证据位置。

## 1. 实测规律（把 40 节收敛成三条）

| # | 规律 | 证据 |
|---|---|---|
| R1 | **只有"语义 / 身份"类因子能越过噪声带**：概念归并 +1.4pp、神经稀疏子词 +3.4pp | §15 §18 §31 §36 §38 |
| R2 | **"几何 / 顺序"类因子在长文档检索上恒为负**：有序对齐 −12pp、邻近平移 −1.7pp、结构匹配 ~0 | §12 §19 §21 §38 |
| R3 | **因子是否有效是查询条件化的**：扩展的逐查询 oracle 上限 +2.36pp，但只有约 9% 查询受益；硬门只能回收很小一部分（+0.2pp） | §13.3 §23 §39.2 §40 |

## 2. 为什么继续"加因子 / 调门"收益递减

- **硬门上限低**：门要么开要么关，而收益集中在少数查询上，弱特征（训练集准确率 0.659）
  必然把收益稀释（§40）；
- **名次融合（RRF）丢信息**：两路接近时（BM25∩RRF 0.903）融合无增益；两路差异大时
  （OAC 0.652）又被类型偏置带偏（dsh-pod 实测 topic 286 vs trait 30）；
- **加性因子会互相抵消**：邻近因子在 BM25 之上为负，叠在概念因子上仍为负（§38.5）。

## 3. 跨数据集检验：唯一"正收益因子"没有迁移（2026-11-17 补测）

同一个 `sgl` 外壳（概念因子打开、邻近关闭），在 arguana 上重跑：

| 数据集 | 配置 | bm25 | 概念因子版 | Δ |
|---|---|---:|---:|---:|
| scifact | §38.5 | 0.6647 | 0.6788 | **+0.0141** |
| arguana | 本节 | 0.3162 | 0.3154 | −0.0008 |

概念因子在第二个数据集上**没有复现**。这与 §16、§18.2 的结论一致：
"概念因子本身的价值"从未被证明，能迁移的是"β 加权"这个结构。

⇒ 以"泛用性"为准绳时，当前唯一稳定成立的东西是 **BM25 这个地板**；
其余因子要么是单数据集上的点估计（概念），要么依赖大模型（稀疏，+3.4pp）。

## 4. 重设计原则（可解释 / 泛用 / 抗过拟合）

### 4.1 三条硬约束

| 约束 | 含义 | 反例（本仓已证否） |
|---|---|---|
| **C1 不拟合融合权重** | 外壳的组合规则由公式给出，不从标签里学系数 | RRF 之外的线性加权、LTR 的 5–8 个系数 |
| **C2 因子必须由可观测条件触发** | "什么时候用"要能一句话说清，而不是靠分类器判断 | QPP 硬门（训练集准确率 0.659，+0.2pp） |
| **C3 因子必须跨数据集同向** | 同一份配置在 ≥2 个数据集上 Δ 同号，才允许进主线 | 概念因子（scifact +1.4pp / arguana −0.1pp） |

### 4.2 满足 C1–C3 的因子形态

```text
score(q,d) = Σ_{t ∈ q ∩ d} evidence(t,d)          ← 固定公式，无系数
           + trigger(q,d) · bonus(t,d)            ← 条件触发，0/1 或由语义定义
```

`trigger` 只能是**可观测的语义条件**，候选（都可解释、无参数）：

| 条件 | 语义 | 为什么可解释 | 状态 |
|---|---|---|---|
| 查询词不在语料词表（df=0） | "字面根本搜不到，只能扩展" | 不需要置信度模型；OOV 是二元事实 | 待测 |
| 查询词与文档词共享词干（lcp 比例） | "同一概念的形态变体" | 形态学事实，非统计拟合 | 已测（概念归并，但未跨集复现） |
| 查询与语料语种不同 | "必须跨语言映射" | 语种检测是确定性判断 | 已有 `BilingualLexicon` |

### 4.3 验证协议（先于实现，避免"刷分式"选择）

1. **数据集**：scifact（英/科学短文本）+ arguana（英/长论证）+ qbqtc（中文短标题）；
2. **配置冻结**：一份配置跑三个集，**不允许按数据集调参**；
3. **判据**：三集 Δ 的**符号一致性**优先于单集幅度；任一次反向 → 该因子不进主线，
   只记录为"数据集特定"；
4. **证据强度**：单 seed 只报"是否越过 Δ_min"；跨集合计只做方向统计，不做分数平均；
5. **消融**：关掉触发条件（变成全量应用）必须更差，否则说明触发条件没有信息。

### 4.4 与"自成一派"的关系

这套约束下，外壳依然是**一个公式**（不是多路投票），但它的"智能"来自
**因子的语义与触发条件**，而不是系数。内核的职责收窄为两件事：
产出**身份映射**（概念/双语）与**可判定的触发条件所需的事实**（词表、语种、形态），
不再产出"该不该用我这个因子"的置信度分数。

## 5. 迁移到 rs 与 dsh-pod

| 场景 | 因子向量 | 备注 |
|---|---|---|
| `relation-search` | BM25 分、AST 结构命中、符号命中、路径/类型权重 | AST 只做候选补位，不参与打分（§39 的结论） |
| dsh-pod 记忆召回 | BM25 分、OAC 分（**作为特征而非路由**）、主体权重、强度先验 | 把 OAC 从"影子路由"改成"一个特征"，正是本文档的核心主张 |

## 6. 不做清单

- 不拟合融合权重、不用分类器当门（C1/C2）；
- 不再尝试"参数自由的词项模型"（DPH/Dirichlet 已验证更差，§38.5）；
- 不再把几何因子加到长文档检索上（§12 §38）；
- 不再用硬门控做主路径（§40）；
- 不再做词级有损投影（§39.1）。
