# 重设计方案：从「硬门 / 名次融合」到「因子向量 + 内核学系数」

> 依据：本仓 §1–§40 的全部实测（尤其 §13、§18、§23、§33、§36–§40），
> 以及 dsh-pod 记忆召回的 103 条 trace 对照（BM25∩RRF 0.903、OAC∩RRF 0.652）。
> 本文件只写由数据支持的推断；每条推断后面标注证据位置。

## 1. 实测规律（把 40 节收敛成三条）

| # | 规律 | 证据 |
|---|---|---|
| R1 | **只有"语义 / 身份"类因子能越过噪声带**：概念归并 +1.4pp、神经稀疏子词 +3.4pp | §15 §18 §31 §36 §38 |
| R2 | **"几何 / 顺序"类因子在长文档检索上恒为负**：有序对齐 −12pp、邻近平移 −1.7pp、结构匹配 ~0 | §12 §19 §21 §38 |
| R3 | **因子是否有效是查询条件化的**：扩展的逐查询 oracle 上限 +2.36pp，但只有约 9% 查询受益；硬门只能回收很小一部分（+0.2pp） | §13.3 §23 §39.2 §40 |

## 2. 为什么继续"加因子 / 调门"收益递减

- **硬门上限低**：门要么开要么关，而收益集中在少数查询上，弱特征（训练集准确率 0.659）
  必然把收益稀释（§40）；
- **名次融合（RRF）丢信息**：两路接近时（BM25∩RRF 0.903）融合无增益；两路差异大时
  （OAC 0.652）又被类型偏置带偏（dsh-pod 实测 topic 286 vs trait 30）；
- **加性因子会互相抵消**：邻近因子在 BM25 之上为负，叠在概念因子上仍为负（§38.5）。

## 3. 重设计：因子向量 + 内核学系数（LTR 化）

### 3.1 形态

```text
候选（倒排召回 top-N，只负责"进池"）
   │
   ├─ f1 = BM25 分数（归一化后）
   ├─ f2 = 神经稀疏内积（子词空间，§36 的 0.6985 那一路）
   ├─ f3 = 概念匹配命中数 / 查询词数（§31 那一路）
   ├─ f4 = 标题命中、文档长度等结构特征
   └─ f5 = 首轮置信度（top1 优势，§40 用过的特征）
        │
        ▼
   score = w · f     （w 由内核在 train split 上拟合，约 5–8 个系数）
```

- **外壳**：固定公式 `score = Σ w_k · f_k`，零手工权重；
- **内核**：只学 `w`（5–8 个标量），在 809 条 train 查询上做 pairwise / listwise 拟合；
- **与 RRF 的区别**：不是名次投票，是**同一单位（分数）的线性组合**；
- **与手调融合的区别**：权重来自 train split 拟合，有嵌套交叉验证兜底。

### 3.2 为什么这次可能成立

| 条件 | 现状 |
|---|---|
| 每个因子单独有正收益 | ✅ BM25、概念、稀疏三条都单独过线（§36 §38） |
| 因子之间信息不完全重叠 | ✅ 稀疏与概念的分词空间不同（§39.1 显示不能无损投影） |
| 有足够训练数据 | ✅ 809 条 train 查询（scifact），5–8 个系数不会过拟合 |
| 外壳零超参 | ✅ 权重是内核产物，外壳只做点积 |

### 3.3 判据（预注册后一次读数）

- **P1**：test 上 nDCG@10 > **0.6985**（当前最强单路 bilingual-sparse），且 ≥ Δ_min；
- **P2**：消融——任去掉一个因子，分数应下降；若某因子权重≈0，说明它无信息，删掉；
- **P3**：嵌套 5 折交叉验证的 train 内部一致性：折间权重符号一致；
- **Kill**：若 ≤ 0.6985，说明"因子线性组合"上限已到，转 3.4 的备选。

### 3.4 备选（若 P1 失败）

1. **软门控**：把"要不要扩展"从 0/1 改成连续权重 `g(x) ∈ [0,1]`，`score = base + g(x)·bonus`，
   `g` 与 `w` 一起在 train 上拟合（比硬门平滑，能部分兑现 §13 的 oracle 上限）；
2. **结构化邻近**：只在"整串查询作为短语出现"时加成（relation-search 的做法），而不是任意相邻对；
3. **词表对齐的另一种做法**：不做子词→整词的有损投影（§39.1 已证否），
   而是让外壳直接持有 SPLADE 词表（即 §36 的做法），把概念因子也映射到同一空间。

## 4. 迁移到 rs 与 dsh-pod

| 场景 | 因子向量 | 备注 |
|---|---|---|
| `relation-search` | BM25 分、AST 结构命中、符号命中、路径/类型权重 | AST 只做候选补位，不参与打分（§39 的结论） |
| dsh-pod 记忆召回 | BM25 分、OAC 分（**作为特征而非路由**）、主体权重、强度先验 | 把 OAC 从"影子路由"改成"一个特征"，正是本文档的核心主张 |

## 5. 不做清单

- 不再尝试"参数自由的词项模型"（DPH/Dirichlet 已验证更差，§38.5）；
- 不再把几何因子加到长文档检索上（§12 §38）；
- 不再用硬门控做主路径（§40）；
- 不再做词级有损投影（§39.1）。
