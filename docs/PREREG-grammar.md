# PREREG：语法（结构）先验因子 `grammar-v0`

> 写于看过本实验任何读数之前。判据与决策规则写定后不再修改，只追加「结果」一节。

## 1. 问题

先验因子目前只有三种：`token_confidence_list`（关联词）、`field`（字段）、`concept`（概念归并）。
本节引入第四种——**语法/结构类**：

> 一个 token 在句子里的**语法角色**（功能词 / 谓词 / 名词性 / 修饰性 / 技术标识符），
> 能否作为先验因子提升排序？

**为什么这次可能跟以前不一样**：此前被证伪的三个方向（`field_idf`、`idf_lift`、`saliency`，
`docs/RESULTS.md` §15.2）全部是 `df` 的**单调变换**，而 BM25 的 idf 已经覆盖了 df。
语法类**不是** df 的函数：一个高频名词和一个高频介词可以有相同的 df、完全不同的语法角色。
这是第一个「原理上 BM25 看不到」的 per-token 信号。

**明确界定**：这里要的是**结构关系**，不是语义关系。要区分的是「形容词 vs 介词 vs 动词」，
不是「褒义 vs 贬义」。因此特征只用正字法与分布结构（大小写、位置、邻居多样性、df），
**不引入任何语义资源**。

## 2. 因子形状与边界

| 层 | 内容 | 谁决定 |
|---|---|---|
| 类别集合 | `K = 16` 个结构类 | **固定超参**（内核架构的一部分，不是判定规则） |
| 结构特征 | 12 维（见 §4），全部来自语料原始文本 | 语料统计（无监督） |
| 类别中心 | `μ_1..μ_K`（K×d 个数）+ 温度 `τ` | **内核学习**（无监督聚类，不碰 qrels） |
| 先验因子 | `token → [p(k|t)]_{k=1..K}`（软分配，K 维单纯形） | 内核输出 |
| 类乘子 `λ_1..λ_K` | 外壳超参（K 个标量） | **外壳**，在 train split 上调 |

**分工理由**（`docs/KERNEL.md` §0 的两条硬约束）：

- 因子只表达事实：「这个 token 的语法类分布是 p」。**不含** `λ`、不含「该乘多少」；
- `λ_k` 是**用法**，属于外壳算法超参，进 `AdapterInfo.config`；
- 因此换外壳（比如改用 `λ` 做查询扩展门控）不需要重定因子。

内核网络参数量 = `K·d + 1 = 16×12 + 1 = 193`，在 `AGENTS.md` 定的 ≤10k 预算内。

软分配用 RBF + softmax：

```text
p(k|t) = softmax_k( -||x_t - μ_k||² / τ )
```

## 3. 训练方案

### Stage A：无监督类归纳（内核，不读 qrels）

1. 对语料每个 token 算 12 维结构特征（§4）；
2. 特征按语料内 z-score 标准化（避免 df 这类大尺度特征支配距离）；
3. `K = 16` 的 k-means（k-means++ 初始化，固定 seed=20261112，20 次重启取 inertia 最小）；
4. 用最终质心算 RBF 软分配，得每个 token 的 `p(k|t)`。

产物 = 先验因子。**这一步完全不看 qrels**，`trained_on` 如实写「语料内统计（无监督）」。

### Stage B：外壳校准（`λ_k`，只在 outer-train 上）

1. 打分：`score(d) = Σ_t idf(t) · (Σ_k p(k|t)·λ_k) · tf_norm(t,d)`；
2. `λ_k` 初值全 1（此时**逐位等于 `bm25`**，这是等价性门）；
3. 在 **outer-train（663 条）**上按 `nDCG@10` 做坐标搜索（每个 `λ_k` 扫
   `{0.25, 0.5, 0.75, 1.0, 1.25, 1.5, 2.0}`，两轮），**目标直接是 harness 指标**；
4. **heldout（146 条）不参与任何一步拟合**，只用于最终判决。

## 4. 结构特征（12 维，全部结构/正字法）

| # | 特征 | 为什么是「结构」而不是「语义」 |
|---|---|---|
| 1 | `log df` | 频率（必带，否则无法与 df 对照公平比较） |
| 2 | `cap_ratio` | 原始文本里首字母大写的出现比例（专名 / 句首） |
| 3 | `sentence_initial_ratio` | 出现在 `.?!` 或换行之后的比例 |
| 4 | `title_ratio` | `df_title / df` |
| 5 | `mean_rel_pos` | 在文档中的平均相对位置 |
| 6 | `left_neighbor_ttr` | 左邻居 type/token 比（功能词邻居极杂） |
| 7 | `right_neighbor_ttr` | 右邻居 type/token 比 |
| 8 | `mean_log_df_left` | 左邻居的平均稀有度 |
| 9 | `mean_log_df_right` | 右邻居的平均稀有度 |
| 10 | `has_digit_ratio` | 含数字的出现比例（基因名 / 编号） |
| 11 | `all_alpha_ratio` | 纯字母的出现比例 |
| 12 | `mean_len` | 平均字符长度 |

**明确不用**：任何后缀表（`-ing` / `-ed` / `-s`）、任何停用词表、任何语义资源、任何预训练模型。
类别必须从分布结构里自己长出来，否则就是「手写规则换了个位置」。

## 5. 对照臂（缺一个都会导致错误归因）

| 臂 | 作用 |
|---|---|
| `bm25` | 基线 |
| `grammar-λ`（K=16） | 待测机制 |
| **`df-bucket-λ`（16 桶）** | **关键对照**：按 log df 等频分 16 桶、每桶一个 λ，参数量与 `grammar-λ` 相同。若两者增益相当 ⇒ 归因给频率，**不是**语法 |
| **`random-λ`（16 类随机分配）** | **测量自检**：随机类不应产生增益。若它也有增益 ⇒ 拟合过程本身有问题（`ml-experiment-attribution` §2.2），全部读数作废 |

## 6. 决策规则（预注册，事后不改）

记 `Δ_grammar` = `grammar-λ` 相对 `bm25` 的 Δ nDCG@10（heldout，配对 bootstrap），
`Δ_df` = `df-bucket-λ` 相对 `bm25` 的同量，各自的 `Δ_min = 2×SE`。

按顺序判定，**命中即停**：

| 序 | 条件 | 结论 |
|---|---|---|
| 0 | `random-λ` 的 `\|Δ\| ≥ Δ_min` | **测量作废**，先修拟合过程，不出任何结论 |
| 1 | 类别与 df 桶的互信息归一化 ≥ 0.5 | **类别是频率代理**，不建外壳，记录为「结构类未脱出 df」 |
| 2 | `Δ_grammar < Δ_min` | 该口径下未测出超过噪声带的增益，不建外壳 |
| 3 | `Δ_grammar ≥ Δ_min` 且 `Δ_df < Δ_min` | **语法类携带 df 之外的信息** ⇒ 建 `grammar-bm25` 外壳 |
| 4 | `Δ_grammar ≥ Δ_min` 但 `Δ_grammar − Δ_df < Δ_min(class−df)` | 增益可被 df 桶解释 ⇒ 不建，记录「与频率不可区分」 |

## 7. 次要读数（不论主判据如何都报）

- `Δ recall@100`、`Δ hit@10`、查询 p50；
- **干预非零性冒烟**（R29）：`grammar-λ` 改动了多少查询的 top-10，门槛 ≥10%；
- 每个类别的成员样例（最高 df 的 15 个），供人工判断「这是不是语法类」；
- `λ_k` 的学习结果与各簇的「功能词程度」是否一致。

**诚实声明**：`K=16` 的无监督聚类产生的是**分布结构类**，不保证与语言学 POS 标签一一对应。
若人工核对后发现簇只是频率分段，必须在文档里如实写「这是频率类，不是语法类」，
不得因为名字叫 `grammar` 就宣称它测了词性。

## 8. 明确不做

- 不引入预训练 POS tagger（污染风险 + 不是本仓内核）；
- 不写后缀/停用词规则；
- 不在 heldout 上调 `λ`，不用 arguana test 调任何东西（该额度已在
  `docs/PREREG-concept-transfer.md` 用掉）；
- 不在中文语料上宣称有效（结构特征里的 `cap_ratio` / `sentence_initial_ratio` 对中文无意义）。

## 9. 结果

**第 1 次读数作废（决策规则 #0 命中）**：用无监督 16 聚类产出类别，`random-λ` 臂逐位复现了
`grammar` 臂的 +0.02516 ⇒ 测量被判定为「在任意 16 分箱上拟合 16 个自由标量」，
不是语法类。按本文件 §6 #0，全部读数作废、不建外壳。

**第 2 次读数（受控版本）**：类别换成 gold 词性标注（CRAFT + UD English-EWT），
零假设对照从「纯随机」收紧为 **df 分层置换**（保留类的规模与 df 结构）。结论是**零**：
`grammar_pos` Δ = −0.00018（噪声带内），且低于 `df_strat_perm` 的 +0.01505。

完整语料来源、覆盖率、读数与边界见 [`docs/RESULTS.md`](RESULTS.md) §19。
本节 §1–§8 的判据**未被修改**，只追加了这次结果；第 1 次作废的原因记在 §19.4。
