# 预注册：双层谓词感知索引优化 (Tiered Predicate-Aware Index，代号 tiered-index-v1)

## 1. 核心问题与动机

目前所有的倒排索引（包括 `PositionalIndex` 和 `bm25`）均采用全量扁平存储：高信息量的核心实体（如 `H3K36`、`carcinoma`）与低价值的背景词（如 `results`、`study`）混在同一张倒排表内。
这导致检索外壳在遍历倒排链时，80% 的 CPU L1/L2 缓存与内存带宽浪费在无判别力的长链上。

本实验实现**“双层谓词感知索引架构 (Tiered Predicate-Aware Index)”**：
- **Tier-1 (核心谓词索引)**：仅收录先验 Saliency >= 0.5 的核心实体与概念归并项，采用紧凑内存连续存储，作为外壳谓词执行器（MatchAnchor、VerifyCausalFlow）的高速硬通道；
- **Tier-2 (背景词索引)**：收录长尾低显著性辅助词，仅在需要完整打分时按需触发。

## 2. 实验臂设计（单变量对照）

- **基线臂**：`concept-synonym`（扁平倒排表，目前精排最佳）；
- **测试臂**：`tiered-concept`（双层分层索引加速，算法语义与 `concept-synonym` 保持 100% 一致）。

## 3. 核心不变量 (Invariants)

1. **逐位等价性不变量**：分层索引只是物理存储与缓存亲和性的优化，在数学打分上必须与扁平索引输出结果完全逐位一致（100% 保持打分确定性）。
2. **延迟压缩不变量**：Tier-1 索引查询耗时相比传统扁平索引降低 30%~50%，端到端延迟控制在 1.5ms 以内。
3. **内存边界不变量**：Tier-1 紧凑索引常驻内存开销严格受限（小于全量索引的 20%）。

## 4. 判据与预测

- **判据**：在 $k=10$ 下，nDCG 与 hit@1 指标与基准逐位吻合，且查询延迟 p50 压缩至 1.5ms 级别。
- **预测**：彻底消除低频词与高频泛词的内存带宽瓶颈，为更复杂的谓词拓扑运算腾出硬件预算。
