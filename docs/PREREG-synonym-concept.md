# 预注册：基于语义同义概念内核的检索突破 (synonym-concept-v1)

## 1. 核心问题与动机

现有 `concept-v1` 仅通过字符前缀比对（LCP >= 70%）挖掘形态变体（如 cell <-> cells, e2f <-> e2fs）。这种词缀形态归并虽然取得了 +0.0154 的稳定增益，但面对字面完全不同的专业同义词（如 cancer <-> carcinoma/tumor, senescence <-> aging）完全失效。

这是传统 BM25 面对的不可逾越之墙（词汇鸿沟，Vocabulary Mismatch）。本实验通过构建真正的“语义同义词概念内核”，突破字面形态限制：
- 在离线阶段利用语料上下文分布与紧凑向量嵌入空间，挖掘高置信度同义词概念对（Cosine Sim >= 0.82 且具有相似的词频分布特征）；
- 严格遵循“先验证据而非用法”的工件契约，生成同构的 `concepts.json`；
- 外壳直接消费，零增加在线计算成本，纯 CPU 毫秒级倒排检索。

## 2. 实验臂设计（单变量对照）

- **基线臂**：`bm25`（传统词法无归并）；
- **词缀形态归并臂**：`concept-v1`（LCP >= 70% 屈折形态归并，现役主力）；
- **语义同义词扩展臂**：`concept-synonym-v1`（包含形态屈折 + 真正的跨词汇语义同义词概念归并）。

## 3. 核心不变量 (Invariants)

1. **同构消费不变量**：工件必须与现有的 `concepts.json` 保持 100% 同构，外壳消费代码无需为同义词引入任何特殊硬编码或新算法。
2. **保守性与抗漂移不变量**：同义词映射必须经过严格阈值筛选（相似度高、且必须在语料共现或上下文分布上有充分支撑），严禁将上位词或泛化词错误归并为同义词（如严禁把 disease 归并为 cancer）。
3. **CPU 极速不变量**：因为依然是离线映射，检索延迟必须严格维持在 2~3ms 级别，零运行时模型推理。

## 4. 判据与预测

- **判据**：在 $k=10$ 下，nDCG@10 相比 `concept-v1`（0.6801）进一步提升，且 hit@10 显著提升。
- **预测**：真正跨越字面鸿沟，打捞以前完全因为用词不同而搜不到的硬漏文献。
