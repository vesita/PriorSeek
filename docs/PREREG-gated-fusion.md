# 预注册：自适应查询门控混合检索 (Learned Gated Fusion，代号 gated-fusion-v1)

## 1. 核心动机

当前 `hybrid-rrf` 虽然通过无参数的 RRF 融合冲破了 nDCG 0.70 的大关，但它是基于两路地位完全平等的假设。而在 scifact 等专业科学语料上，查询表现出极大的异质性：
- **语义改写密集型查询**：极度依赖 `dense` 路的泛化召回；
- **精确专业词汇查询**：极度依赖 `concept-synonym` 路的词法精准锚定。

机械的 RRF-60 无法感知查询的属性，存在权重稀释风险。我们需要一个微型的神经网络感知器，根据查询特征动态动态预测融合权重 $\alpha$。

## 2. 实验臂设计 (单变量对照)

- **基线臂**：`hybrid-rrf` (机械等权 RRF)；
- **测试臂**：`gated-fusion` (微神经网络预测权重，通过 `alpha * lexical + (1-alpha) * dense` 融合)。

## 3. 架构不变量 (Invariants)

1. **确定性推断不变量**：门控网络（轻量 MLP）的权重在离线训练后固化，线上推理必须是确定性逻辑，禁止任何运行时动态训练。
2. **零 GPU 依赖不变量**：门控网络推理必须在 Rust 中利用纯 CPU 加速完成，严禁引入重型 Tensor 库，仅限简单的矩阵乘法（矩阵维度：输入特征 4x1 -> 隐藏层 16x1 -> 输出 alpha 1x1）。
3. **零超参不变形**：Alpha 权重必须完全由网络根据查询特征动态计算得出，严禁人工微调 alpha 的范围边界。

## 4. 判据与预测

- **判据**：nDCG@10 显著优于 RRF-60，且对“不同属性（泛化 vs 精确）”查询的命中分布更加均衡。
- **预测**：通过动态权重分配，在保证精确命中的同时，彻底打通语义查询的边界。
