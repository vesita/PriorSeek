# 预注册：基于先验因子动态调制的 BM25 外壳 (saliency-modulated BM25)

## 1. 核心问题与动机

上一轮实验（`docs/RESULTS.md` §24）表明：
全局常数下界偏置 $\delta=0.5$ 虽然在短文本（`scifact`）上降低了搜索缺失率，但在长论证段落（`arguana`）上导致 nDCG 下跌 3 个点。
物理归因明确指出：**长查询中包含大量低信息量的泛化常见词，全局 $\delta$ 会给每一个常见词命中强行加分，造成多词累加的假阳性灾难**。

解决途径：**让外壳的物理参数与内核产出的先验因子（Token Saliency $S(t) \in [0, 1]$）动态绑定**：
1. $\delta_{\text{eff}}(t) = \delta_{\text{base}} \cdot S(t)$：只有核心高显著性专有名词才享有防截断下界保证；常见弱相关词 $\delta \approx 0$；
2. $k_{1,\text{eff}}(t) = k_{1,\text{base}} \cdot (1 + \lambda \cdot S(t))$：核心词保持更陡峭的非饱和曲线，普通修饰词快速饱和。

## 2. 实验臂设计（单变量对照）

- **基线臂**：`bm25`（传统 Okapi BM25）；
- **全局偏置臂（负对照）**：`bow-plus`（全局固定 $\delta=0.5$）；
- **动态先验调制臂**：`saliency-bm25`（由内核 Saliency 因子动态控制 $\delta_{\text{eff}}$ 与 $k_{1,\text{eff}}$）。

## 3. 评测数据集

- `scifact`：科学摘要基准；
- `arguana`：长查询、长论证段落（检验是否成功遏制了全局 $\delta$ 导致的假阳性崩塌）。

## 4. 判据与预测

- **退化等价性**：当 Saliency 全为 0 或未提供时，严格逐位退化为传统 BM25（G1 门禁）；
- **长文本假阳性遏制**：在 `arguana` 上，动态调制后的表现应显著优于全局 $\delta=0.5$（反弹收复失地）；
- **短文本核心收益**：在 `scifact` 上，保持高核心词匹配质量，nDCG 稳定越过噪声带。
