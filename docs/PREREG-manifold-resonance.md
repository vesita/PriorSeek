## 1. 核心理论模型与范式转移

### 传统晚期投票的局限
传统混合检索在输出的离散列表做算术叠加：
`RRF = sum_r 1 / (60 + rank_r(d))`

### 先验空间共振理论 (Manifold Resonance)

1. 离散先验概念覆盖势能：
   `phi_lex(d, q) = sum_{t in q} saliency(t) * idf(t) * tf_eff(c(t), d) / (tf_eff + k1 * ...)`
2. 连续语义向量流形投影：
   `phi_dense(d, q) = <q_dense, d_dense>`（L2 归一化余弦投影）
3. 空间非线性相干共振算子：
   `Resonance(d, q) = (1.0 + phi_lex(d, q)) * exp( gamma * phi_dense(d, q) )`

### 物理自愈机制（消除两大经典病态样本）
- 病态 A（词频欺骗/歧义语境）：词法分极高但语义方向偏离，`exp(gamma * phi_dense)` 呈指数级衰减，瞬间压制伪词频；
