# 预注册：全息相干势能场算子引擎 (cpf)

- 日期：2026-11-14
- 目标：彻底废除“晚期列表投票（RRF）”与“机械加权”的拼凑范式，在单一数学方程中内生融合离散概念饱和、连续流形相干、合取命题完备性与反事实因果防御四大核心灵魂。

## 1. 核心理论模型与一体化方程

传统系统将词法、向量、因果作为独立算法运行，最后在离散排名上机械相加。
CPF 引擎将其重构为查询在文档多极势场中激发的全息相干总能量：

TotalEnergy(d, q) = gamma * <q_dense, d_dense> + sum_{j in q} w_j * ln( 1.0 + Phi_lex(j, d) ) + Phase(q, d)

### 方程内在四大物理不变量
1. 连续流形相干项：gamma * <q_dense, d_dense>
   使用 SVD 白化连续语义向量，消除高维锥形各向异性背景，捕捉跨词面连续语义流向；
2. 离散概念饱和项：sum_{j in q} w_j * ln( 1.0 + Phi_lex(j, d) )
   外层严格凹函数 ln(1 + Phi) 自然内嵌边际递减饱和，彻底扼杀单一罕见词的词频垄断欺骗；
3. 合取命题完备性：sum_{j in q}
   必须多个查询概念探针在文档不同局域均产生势能响应，总能量才能显著累加，天然抵抗部分重合的偏题文档；
4. 因果相位相干项：Phase(q, d)
   同向因果激发正相干能量 (+0.25)，反事实对立激发强阻尼相消 (-0.75)。
