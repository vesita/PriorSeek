# 预注册：查询感知动态 RRF 路由先验 (query-gated-rrf)

- 日期：2026-11-14
- 目标：验证在保持检索外壳零超参的前提下，通过离线内核从训练集拟合查询特征先验（平均 IDF、最高 IDF、词数熵），动态调节三路异构检索（概念同义路 / 稠密向量路 / 显著性词法路）的 RRF 倒数秩融合权重，能否打破静态 RRF 权重的上限。

## 1. 核心理论假说

静态三路 RRF 融合公式：
$$score(d, q) = \frac{w_1}{60 + rank_1(d)} + \frac{w_2}{60 + rank_2(d)} + \frac{w_3}{60 + rank_3(d)}$$
其中 $(w_1, w_2, w_3) = (1.0, 1.0, 0.5)$ 为固定常量。

但在物理现实中：
- 当查询具有极高 IDF（包含罕见医学专有名词、突变位点）时，词法路（`concept-synonym`）特异性极高，稠密向量易发生语义泛化漂移；此时 $w_1$ 应占主导；
- 当查询为低 IDF、多修饰语的复杂命题假说时，词法路面临词汇鸿沟，连续语义流（`dense`）更为稳健；此时 $w_2$ 应占主导。

**哲学守卫**：
外壳代码不包含任何人工硬编码规则或调优阈值；
所有路由权重向量 $\mathbf{w}(q) = (w_1(q), w_2(q), w_3(q))$ 完全由离线训练内核根据查询特征生成为带 sha256 的工件。

## 2. 实验对照臂

- **基线 A（静态双路）**：`hybrid-rrf` (nDCG@10 = 0.7012)
- **基线 B（静态三路）**：`tri-hybrid-rrf` (nDCG@10 = 0.7057, hit@1 = 57.33%)
- **实验臂**：`query-gated-rrf` (动态消费内核先验工件权重，外壳无参)

## 3. 判据与预测

- **正向判据**：
  在 SciFact 300 条计分测试集上，`query-gated-rrf` 的 nDCG@10 须显著超过静态三路基线（> 0.7057），且 hit@1 维持在 ≥ 57.00%。
- **算力与延迟判据**：
  纯 CPU 执行，单次查询 p50 延迟不得超过 3.0ms。
