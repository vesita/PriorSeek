## 0. 要回答什么

一句话：**把 `seq` 内核里「时序关联」的权重从手调改成在 train 上学出来，能不能让 λ>0 从拖后腿变成有增益？**

现状读数（均来自 `docs/RESULTS.md` §8，单次运行）：

- scifact 上 `bm25` nDCG@10 = **0.6647**；`seq`（λ=0.5，order1=order2=1） = **0.6515**；
- 手调 λ 扫描最好的是 λ=0.1 → **0.6655**（相对 bm25 +0.0008，单次运行，未做显著性）；
- 消融：`orders=[1]`（0.6583）优于 `[1,2]`（0.6515）；`ordered=false`（0.6509）更差；窗口越大越差。

**猜想**：统计版的问题不是「权重系数没调好」，而是「order=2 的边本身是噪声」。
如果学习器能从 train 上自己发现这点，学到 `a2 → 0` 且 `a1 > 0`，则 test 上应不劣于 bm25；
反之若学到 `a2` 明显为正，说明我们的消融结论在 train 上不成立。

**预测值（跑前登记）**：

| 量 | 预测 |
|---|---|
| `a2 / a1`（order=2 相对 order=1 的权重比） | **< 0.3**（倾向于 0） |
| `a1`（λ=1 口径下的 order-1 权重） | 0.05 – 0.3 |
| test nDCG@10（相对 bm25 的 Δ） | **+0.000 ± 0.006**，即大概率 < Δ_min（测不出差异） |
| 2 seed 的 `a1` 极差 | ≤ 50% 相对差（若远超，说明拟合不稳、结论作废） |

## 3. 打分与参数化

```text
score(q,d) = s_uni(d) + a1 · s1(d) + a2 · s2(d)
  s_uni  = Σ_t idf(t)·tf·(k1+1)/(tf + k1·(1-b+b·len/avg_len))
  s1/s2  = 分别在 order=1 / order=2 的贡献（Σ e(a,b)·(1+ln min(c,max_matches))）
```

等价写法（适配器侧）：`λ_seq = 1`，`SL_SEQ_W_ORDER1 = a1`，`SL_SEQ_W_ORDER2 = a2`。
只有 `a1`、`a2` 的自由度是 2：`λ`、`w1`、`w2` 的任意缩放组合给出同一个排序。

**目标函数（代理）**：pairwise logistic，`L = mean log(1 + exp(-(s_pos - s_neg)))`，
每查询每正例采 20 个负例（从语料均匀采样、排除该查询的正例），`a1, a2 ≥ 0`。

> 代理 ≠ 指标：所以我们同时报 train 上的 **nDCG@10**（直接用指标看），以及代理损失曲线。
> 若代理损失下降但 train nDCG 不涨，这条训练路线视为无效。

## 4. 判据（写死）

| # | 判据 | 门槛 |
|---|---|---|
| **主** | test nDCG@10，`seq`(learned) − `bm25`，**逐查询配对** | `Δ ≥ 2×SE_paired` 且 **2 seed 同号** |
| **方向** | `a2/a1`（2 seed 平均） | **< 0.3**（验证「order=2 是噪声」的猜想） |
| **稳定性** | 2 seed 的 `a1` 相对极差 | ≤ 50% |
| **非劣** | test R@100 相对 bm25 | 掉 ≤ `max(0.005, 2×SE_paired)` |
| **Δ_min** | 报 `Δ_min = 2×SE_paired`；`|Δ| < Δ_min` | **只许写「该口径下未测出差异」** |
| **地板** | 必报随机 / `bm25` / `faq-bm25` 三行 | 必报 |

**判决四档**：
- 档 1：主判据过 + 方向过 → 「学习时序权重有效，且证实 order=2 是噪声」
- 档 2：方向过、主判据不过 → 「学习器复现了消融结论，但没带来增益」← **本次最可能的落点**
- 档 3：方向不过 → 「train 上 order=2 不是噪声，我们此前的消融结论不成立」
- 档 4：稳定性不过 / N1–N4 任一不过 → **作废，不出结论**

## 5. 不做什么（范围边界，按 2026-11-10 定）

- 不学全量边权（`e(a,b)` 逐边权重）——那是下一步，且要等本次档位明确；

## 6. 实测（跑后追加，不改上面）

### 6.1 预注册口径的结果：**边界解（权重 = 0），N4 未过 ⇒ 本口径作废**

命令：`cd tools/kernel && uv run python train_seq_weights.py scifact --seed 1 --negatives uniform`
（= PREREG 写死的口径：从全语料均匀采样负例、约束 `a1,a2 ≥ 0`、无归一化）

| 量 | 实测 | 预注册的预测 | 是否命中 |
|---|---|---|---|
| `a1` | **0.0** | 0.05 – 0.3 | ❌ |
| `a2` | **0.0** | — | — |
| `a2/a1` | 无定义（a1=0） | < 0.3 | ❌ 无法检验 |
| 代理损失 | 0.05785 → 0.05785（**400 步完全不动**） | 应下降 | ❌ |
| train nDCG@10 | 0.6701 → 0.6701 | — | — |
| N4 非零性冒烟 | **0.0%**（< 10%） | ≥10% | ❌ **不过** |

按 §2「任一自检不过 ⇒ 不许进 §4 判决」+ §4 档 4：**本次不产生「学习时序权重有效/无效」的结论**。

**未跑 test**：`a1=a2=0` ⇒ `seq` 与 `bm25` 逐位相同（N1 已证），test 上 Δ 恒为 0，跑了也没有信息量。

### 6.2 为什么是零权重（诊断，属于口径修正不是判决）

`a=0` 处的解析诊断（`/tmp/diag_m2.py` 的等价步骤，可复跑）：

| 诊断量 | 值 | 读法 |
|---|---|---|
| `a=0` 处 `dL/da1` | **+0.00458** | 为正 ⇒ 增大 order-1 权重使损失上升 ⇒ 非负约束最优就在 0 |
| `a=0` 处 `dL/da2` | **+0.00077** | 同上 |
| 逐查询 AUC（正例 vs 同查询候选负例，809 条）：`s_uni` | **0.972** | 单字项本身已经很强 |
| 同上：`s1`（order=1 时序） | **0.791** | **时序特征确有信号** |
| 同上：`s2`（order=2 时序） | **0.631** | 弱 |
| 均值 `|du|` / `|d1|` / `|d2|` | 27.9 / 11.9 / 3.8 | 分数未归一，pairwise logistic **严重饱和**（sigmoid ≈ 0 ⇒ 几乎无梯度） |
| 正例上均值 `|s_uni|` vs `|s1|` | 29.6 vs 11.9 | 两者同量级且高度共线：加性 bonus 主要在**放大同一批文档**，不是引入新证据 |

结论：**不是「时序特征没有信息」（单独 AUC 0.79），而是「以加性 bonus 叠在 BM25 上」这个集成方式
在 2 个参数下学不出增益**——单字项已经把可分性做到 0.972，时序项能补的增量很小，而它的量级与长度/重复
正相关，放大后反而伤害排序。

### 6.3 探索性变体（**不属于预注册判决**，仅用于定位瓶颈）

为区分「特征无用」与「代理饱和」，另跑三组（同样只读 train，未看 test）：

| 负例采样 | 逐查询归一化 | `a1` | `a2` | train nDCG@10 | 相对 a=0 | top-10 变化 |
|---|---|---:|---:|---:|---:|---:|
| uniform（预注册） | 否 | 0.0 | 0.0 | 0.6701 | +0.0000 | 0.0% |
| hard | 否 | 0.0 | 0.005 | 0.6701 | −0.0000 | 3.0% |
| hard | **是** | 0.0 | 0.076 | 0.6691 | −0.0010 | 25.6% |
| uniform | **是** | 0.0056 | 0.0287 | 0.6707 | **+0.0006** | 24.7% |

归一化确实解除了饱和（权重能动了），但**最好的变体在 train 上只有 +0.0006 nDCG@10**。
且方向与我跑前的预测**相反**：预测「a1 正、a2→0」，实测「a1≈0、a2 反而是非零的那个」——
但 +0.0006 远小于任何可判定阈值（见 §6.4），所以**不据此下任何方向结论**。

### 6.4 顺带测出的关键校准：**scifact test 的分辨率只有 0.0143**

用既有配对结果（`results/scifact-20261109-181810-seq-fixed`：同一轮的 `seq` 与 `bm25` 逐查询 nDCG）
做 4000 次配对 bootstrap：

- 300 条计分查询，`ΔnDCG@10` 的 **bootstrap SE = 0.00716**，**`Δ_min = 2×SE = 0.0143`**；
- 也就是说：**只有在 scifact test 上 `|Δ| ≥ 0.0143` 才可判定**。

这一条直接改变了我们怎么读 `docs/RESULTS.md` §8 的消融表：那里所有差异（0.0008 / 0.005 / 0.013）
**全部落在噪声带内**，包括「λ=0.5 比 bm25 差 0.0132」这条——它差一点才到阈值。
⇒ 之前那些「λ 越大越差」「order=2 是噪声」的**方向性说法，在 scifact 上都还不成立**，只能标「未测出差异」。

### 6.5 本次的处置

- 预注册口径：**作废**（N4 未过），不出效果结论；
- 有用产物：`KernelArtifact`+train split 契约、2 参数训练器、`ref_score` 分量接口、**Δ_min = 0.0143** 这个分辨率校准；
- 不开 test、不加参数：**下一步要动的是集成方式或测量分辨率，不是参数数量**（见 §7）。

## 7. 下一次要改哪一件事（三选一，按代价排序）

本次已经排除「参数太少」这个方向（2 个参数已经是尺度自由度全部）。剩下的瓶颈只有两个：**集成方式** 与 **测量分辨率**。

| 选项 | 内容 | 代价 | 能回答什么 |
|---|---|---|---|
| **A. 加测试查询量**（推荐先做） | 把 scifact 的 809 条 train 查询留出一部分做 dev，或加一个查询更多的英文集（arguana 1401 / nq-sub 3452 条计分查询）来验证「时序特征到底有没有用」 | 小（数据已有） | 把 `Δ_min` 从 0.0143 降下来；先解决「我们根本看不见小差异」 |
| B. 换集成方式 | 不做「加性 bonus」，改成**用时序边权重重新加权查询词项**（`tf` 权重相乘而非加分），或在 BM25 的 IDF 上做时序修正 | 中（要改外壳打分，需新预注册） | 时序特征能否以「调制」而非「叠加」的方式发挥 AUC 0.79 的信息 |
| C. 学全量边权 | 从 2 个标量扩到按 (阶, 距离桶) 的 8–16 个权重 | 小（同一训练器） | 但按 §6.4，scifact 看不见 <0.0143 的差异 ⇒ **先做 A 才有意义** |

**立即可做的判据**：不做任何模型改动，只在 arguana（1401 条计分查询）上重算一次 `seq` vs `bm25` 的
配对 bootstrap SE，如果 `Δ_min` 明显小于 scifact 的 0.0143，则后续所有小效应实验都应在 arguana 上做。
