# 预注册：神经稀疏先验检索 (Learned Sparse Prior，代号 learned-sparse-v1)

## 1. 核心问题与动机

在既有的混合检索（Hybrid RRF）架构中，系统依赖多路并行检索并在外壳进行排位融合（RRF）。虽然 RRF 解决了 BM25 与连续向量量纲不一致的问题，但本质上依然是“分道检索、事后撮合”的间接方案：
1. 抹平了单路置信度的绝对数值差（第一名领先 10 倍与领先 0.001 倍在 RRF 下位次增益相同）；
2. 外壳仍需维护两套异构索引（倒排链与 384 维稠密向量矩阵），占用两份内存与计算通路。

本实验践行“深度学习做内核产生先验因子，极简外壳做检索执行”的核心原则：
- **内核网络**：利用预训练神经词表投影模型（SPLADE 架构，基于 BERT 词表 MLM 投影，参数量 109M）；
- **先验因子**：模型将文档离线编码为**离散神经稀疏权重向量**（每个 token 对应一个学得的非负重要度权重，自动完成同义词扩展与上下文重要度分配，先验因子形式为 `token_id -> f32`）；
- **外壳检索**：外壳退化为单一的**带权倒排索引**，计算文档与查询的稀疏点积：
  score(q, d) = sum_{t in q intersect d} w(t, q) * w(t, d)
  外壳无需任何手工超参（无 BM25 的 k1/b，无人工启发式截断或混合比例），完全由深度学习内核学得的先验因子决定词权。

## 2. 实验臂设计（单变量对照）

- **基线臂 1（传统词法基准）**：`bm25`；
- **基线臂 2（纯稠密连续向量）**：`dense`（384 维向量点积）；
- **基线臂 3（现有多路融合 SOTA）**：`hybrid-rrf`（词法 + 稠密向量 RRF 融合）；
- **实验臂（单路神经稀疏）**：`learned-sparse`（由神经内核离线烘焙稀疏词权向量，外壳单路倒排点积）。

## 3. 核心不变量 (Invariants)

1. **零运行时深度学习推理不变量**：文档稀疏特征必须全量离线烘焙为二进制文件 `sparse.bin`，在线外壳纯 Rust 编译并执行，纯 CPU 运行，查询延迟控制在毫秒级以内（p50 < 1ms）。
2. **零外壳超参数不变量**：外壳点积打分不设任何人为调节常数，所有语义匹配与重要度全由先验权重承载。
3. **数据隔离不变量**：离线提取脚本只读 `corpus.jsonl` 与 `queries.jsonl`，严禁触碰 `qrels.tsv`，工件带有完整 sha256 校验与模型来源记录。

## 4. 判据与预测

- **判据**：在 k=10 下，`learned-sparse` 的单路检索效果全面超越传统单路 `bm25`（nDCG@10 = 0.6542），并检验其是否能接近或超越双路 `hybrid-rrf`（nDCG@10 = 0.7012）的表现。
- **预测**：
  1. 神经稀疏先验通过离线词项扩展解决词汇不匹配（Lexical Mismatch）问题，nDCG@10 预计突破 0.69，显著优于传统词法检索；
  2. 检索延迟保持在 0.5ms 级别，且内存占用远小于稠密向量全矩阵。
