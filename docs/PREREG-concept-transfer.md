# PREREG：概念归并谓词的跨数据集零样本迁移（scifact → arguana）

> 写于**看过 arguana 的 test 结果之前**。预注册纪律见 `docs/REFERENCE_NOTES.md` §2。
> 本文件在跑完全部评测后**不再修改判据**，只追加「结果」一节指回 `docs/RESULTS.md`。

## 1. 问题

概念归并内核的**判定谓词**是「候选对的语料统计特征 → 是否同概念」，
它的权重 `w`、`b` 在 scifact 的 outer-train 上学出来。问题是：

**这个学到的谓词能否零样本地用在一个没见过的语料上？** 换句话说，
scifact 上学到的「什么算同一个词的两种形态」是否是一个**语言层**的规律，
而不是 scifact 语料特有的过拟合？

## 2. 两臂与唯一变量

| 项 | 内容 |
|---|---|
| 对照臂 | `bm25`（同一分词器、同一 k1/b、同一 idf 定义） |
| 实验臂 | `concept-bm25`（同一份 `w`/`b`，**特征在 arguana 语料上重算**） |
| 唯一变量 | 是否做概念归并 |
| 不变项 | 分词器、k1=1.5、b=0.75、idf 公式、同分排序、k=100、查询集合 |

**为什么这是零样本**：`w`/`b` 完全来自 scifact，arguana 上不做任何拟合、不调任何超参。
carried-over 的只有「谓词的权重」，进因子的候选对与特征全部来自 arguana 自己的语料统计。

## 3. 判据

1. **主判据**：arguana test 上 `Δ nDCG@10 = concept − bm25`，配对 bootstrap（2000 次）。
   - 只有 `|Δ| ≥ Δ_min = 2×SE` 才写成「越过噪声带」；
   - 否则写「该口径下未测出超过噪声带的增益」，**不写「无效」**。
2. **次要读数**：`Δ recall@100`、`Δ hit@10`、查询延迟 p50。
3. **机制自检**：归并后的 token 数与概念组数必须与 arguana 的语料规模相称
   （scifact 上 3617/35948 ≈ 10%；arguana 若低一个数量级，说明候选空间在该语料上不成立，
   那么「把负结果读成谓词没用」是错的，应读成「候选生成器不适用」）。

## 4. 预测值（写死，事后不改）

- 方向：**正向**。
- 幅度：`Δ nDCG@10 ∈ [+0.003, +0.020]`，即**可能不过噪声带**。
- 理由（写下以便事后对照）：arguana 是整段论证文字（长文档），文档长 ⇒ tf 饱和更强、
  长度归一的抑制更强，形态变体的边际收益应当小于 scifact 的短摘要。
- 若观测到 `Δ < −0.01`：说明谓词在另一个语料上**主动有害**，此时应重判谓词的可迁移性，
  而不是把数字归因于噪声。

## 5. test 只看一次

- 本文件写定后，arguana 的 test qrels 只被读取一次（`sl concept-eval --split test`）。
- 不看结果的分桶、不按查询类型再切、不因为结果不理想而换预测值。
- 若需要第二次读数（例如修了 bug 后重跑），必须在本文件追加「第 2 次读数及原因」。

## 6. 明确不做

- 不在 arguana 上训练或微调任何参数（没有 train split，也不新建）。
- 不用 arguana 结果反过来改 scifact 的权重（那会让 scifact 的 heldout 失去意义）。
- 不把 arguana 的绝对分数与 scifact 的绝对分数并列比较（不同数据集指纹，`docs/STANDARD.md` §1）。

## 7. 结果

完整读数见 [`docs/RESULTS.md`](RESULTS.md) §16。一句话：
**方向与幅度都在预测区间内（β=1..5 为 +0.0053..+0.0116，预测 [+0.003, +0.020]），
但同一个 β 下 `uniform`（不需要这个因子）全程优于 `concept`** ——
即「谓词能迁移」成立，「因子比免费权重更有用」不成立。

第 1 次也是唯一一次读数：`results/concept-eval-arguana.json`（`evaluated_on = test`）。
此后**没有**第二次读取 arguana test qrels：为算 `concept` vs `uniform` 的配对区间需要逐查询值，
那会构成第二次读数，因此选择不做，并在 `docs/RESULTS.md` §16.2 里如实标注该对比只有点估计。
