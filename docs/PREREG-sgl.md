# 预注册：因子统合打分（SGL，Sequential Generative Likelihood）

## 1. 问题

现有主线是"多策略投票"：BM25 算一遍、OAC 算一遍、再用 RRF 按名次融合。
dsh-pod 记忆召回的实测暴露了这种结构的缺陷：

- BM25 与 RRF 的选中集合 Jaccard = **0.903**，两路实为一路；
- 唯一有差异的 OAC 与线上 Jaccard = **0.652**，但类型分布严重偏向 topic
  （topic 286 vs trait 30 / event 15），直接替换会挤掉人设与事件。

结论：缺的不是"更好的融合"，而是**一个能把多种先验因子按同一单位合成的打分函数**。

## 2. 假设

一个**顺序生成似然**模型可以在不引入任何融合系数的前提下，同时覆盖
词项特异性、词序、邻近、长度归一，并使 BM25 与 OAC 成为它的退化情形。

## 3. 定义（外壳唯一事实源）

```text
查询 q = [t1..tq]（去重、保 query 顺序），文档 d 为 token 位置序列，长度 len
m = q 中不同词项数

词项证据（对数几率，+1 平滑是加一，不是可调常数）：
    ev(t, d) = ln( (tf(t,d) + 1) / (len * df(t)/N + 1) )

间距证据（几何间距的似然比：聚簇密度 r 对均匀密度 u）：
    r = min(m / len, 1 - 1e-9)
    u = 1 / len
    gap(g) = ln(r / u) + (g - 1) * ln( (1 - r) / (1 - u) )

得分：
    SGL(q, d) = max over A  [ Σ_{i∈A} ev(t_i, d) + Σ_{相邻对} gap(g) ]

A：查询下标严格递增、文档位置严格递增的任意对齐（可跳过查询词）
```

### 3.1 为什么不是"多策略投票"

| 判据 | 投票制（现状） | SGL |
|---|---|---|
| 打分函数个数 | BM25 + OAC + RRF | 1 |
| 跨量纲对齐 | 靠名次倒数 | 不需要（同一单位：nats） |
| 可调权重 | `k1` `b` `rrf_k` `gap` 表 | 0 |
| 消融 | 关掉某一路 | 关掉某一项，公式仍成立 |

### 3.2 退化端点（用于证明"不是补丁"）

| 设定 | 退化形态 |
|---|---|
| `gap_term = false` | 纯词项证据覆盖（≈ 对数几率版 BM25 词袋） |
| `term_term = false` | 纯对齐结构（每命中记 1 分 + 间距似然） |
| 两者都关 | 最长可对齐命中数（覆盖度） |

## 4. 实验臂（同一数据集、同一 k、同一查询顺序）

| 臂 | 说明 |
|---|---|
| 地板 | `bm25` |
| 单路词法强基线 | `concept-synonym` |
| 因子统合（零因子） | `sgl`（只用语料统计：tf / df / len） |
| 对照 | `bilingual-sparse`（神经稀疏，非主线） |

## 5. 判据（先写死，test 只看一次）

- **K1（存在性）**：`sgl` 在 scifact 的 nDCG@10 **≥ 0.6647**（bm25 基线）。低于即作废，不加参数救。
- **K2（结构有效性）**：`gap_term` 与 `term_term` 的消融方向必须与定义一致
  （关掉任一项都不应高于全开；若出现相反结果，说明实现或假设有错，先查实现）。
- **K3（可迁移性）**：同一实现（`sl-engine::SglScorer`）在 dsh-pod 记忆召回上重放，
  trait/event 的选中数不得低于现状。

## 6. 不做

- 不为刷分加入任何乘子（长度权重、间距权重、类型权重）；
- 不接神经稀疏因子作为默认（`bilingual-sparse` 只作对照）；
- 不改兴趣侧（`windowUpper` / `gate` 是另一条线）。

## 7. 风险与预设处置

| 风险 | 处置 |
|---|---|
| 几何假设过强 | 换分布假设（泊松/负二项），仍保持"一个公式、零系数" |
| 短文档仍过度占优 | 先看 K1/K3 数据；若成立则检查 `ev` 的期望项是否该用分桶长度 |
| 对齐 DP 成本 | 复杂度 O(命中数 × 查询长度 × 窗口内前驱)；scifact 上是毫秒级 |

## 8. 结果与偏差记录（实测后补写，不修改上面的判据）

实际实现过程中做了四次模型修正，全部记录在 [`docs/RESULTS.md`](RESULTS.md) §38：

| 版本 | 改动 | nDCG@10 |
|---|---|---:|
| v1 | 全覆盖单调对齐 + Dirichlet 证据 + 几何间距 | 0.6155 |
| v2 | 最大子集对齐（实测退化） | 0.6064 |
| v3 | 覆盖 + 无序邻近 | 0.6185 |
| v4 | 词项因子换成 BM25 term weight | 0.6429 |
| v5 | 邻近改为同向 | 0.6474 |
| v6 | 关掉邻近（消融） | 0.6647（= bm25 逐位一致） |

**K1 未通过**：`sgl` 的最好成绩 0.6474 < 0.6647。按判据 v5 不作废整个方向——因为 v6 证明
外壳的接线是正确的、只是邻近因子在 scifact 上无正收益；SGL 保留为实验台，不进入主线。
