# 因子农场：多个小模型，每个因子一个特化模型

> 与"一个大模型"相对：不追求一个全能编码器，而是让**每个先验因子由一个小模型单独产出**，
> 各自有独立的训练目标与数据，外壳用固定公式做加法。依据见 `docs/RESULTS.md` §1–§49。

## 1. 为什么这样切

| 观察 | 推论 |
|---|---|
| 一个 109M 模型（SPLADE）在四个数据集上同时带来 +0.4 ~ +18pp（§45 §46） | "强因子"确实有效，但它是**一个**模型包办词权、扩展、形态 |
| 把它蒸成 4M 同构学生，KL 损失只有 0.3775（§49） | 一个学生要同时学会词权 + 扩展 + 形态，容量不够 |
| 概念因子在 scifact +1.4pp、arguana −0.1pp（§41） | 单因子只在特定语料有效 ⇒ **必须逐因子独立评测** |
| 硬门、邻近、DPH、分段单元全部落在噪声带（§38–§44） | 组合层不要再加复杂度；复杂度应该放在**每个因子的训练**里 |

结论：**分解比堆叠更有希望**——每个因子只回答一个问题，
用小模型专门学，错了也只错一个因子。

## 2. 因子清单（每个因子 = 一个小模型 + 一张表）

| # | 因子 | 回答的问题 | 模型（建议） | 参数预算 | 训练数据 / 目标 | 外壳用法 |
|---|---|---|---|---|---|---|
| F1 | **词权** | 这个词在这篇文档里多重要 | 6 层 transformer（蒸馏 + listwise） | 4–20M | 语料 + train 查询；教师软目标 + 排序损失 | 加权倒排求和 |
| F2 | **扩展** | 这篇文档还可能被哪些词命中 | T5-small 级 seq2seq（docT5query 配方） | 60M | 语料（无监督生成查询） | 扩展词入索引 |
| F3 | **形态归一** | 这两个词是不是同一个词 | 9 参数判定器（已有 `concept-v0`） | ≤10 | train split 学判定谓词 | 建索引时归并 |
| F4 | **显著性** | 这个词是内容词还是虚词 | 统计量（已有 `saliency-v0`） | 0 | 语料统计 | 词权调制 |
| F5 | **语言/脚本路由** | 查询和语料是不是同一语种 | 规则（Unicode 脚本检测） | 0 | — | 选择加载哪套工件 |
| F6 | **跨语言映射** | 中文词对应哪个英文词 | 词典 + 小模型（OOV 兜底） | ≤5M | 双语词表 + 平行语料 | 查询侧映射 |

**共同约束（C1–C3，来自 `docs/REDESIGN.md`）**：

- C1：外壳只做固定公式（加权求和 / 索引期归并），**不学融合权重**；
- C2：因子只在可观测条件下生效（语种、OOV、形态候选），触发条件必须一句话说清；
- C3：同一份因子在 ≥2 个数据集上 Δ 同号才进主线，否则只登记为"数据集特定"。

## 3. 每个因子怎么训（借鉴开源配方）

| 因子 | 参考 | 本仓的差异 |
|---|---|---|
| F1 词权 | SPLADE / DistilSPLADE：教师软目标 + 稀疏正则 | 教师冻结、学生单语、按语料训；损失改为 **listwise 排序损失 + KL**（§49 证明纯向量 KL 不够） |
| F2 扩展 | doc2query / docT5Query：文档 → 生成查询 → 追加索引 | 用 T5-small 级模型；生成结果直接编译进倒排（§26 的 `sparse-route` 框架已在） |
| F3 形态 | 本仓 `concept-v0`：9 参数判定谓词 | 已有，复用；作用域限定在"共享前缀"候选空间 |
| F5 路由 | 无模型：Unicode 脚本检测 | 已有 `BilingualLexicon` 的语种判断可复用 |
| F6 映射 | 翻译模型（NLLB）或双语词典 | §48 实测：翻译管线把跨语言从 0.24 拉到 0.54，但术语损失大 ⇒ 词典优先、模型兜底 |

## 4. 评测协议（每个因子独立过关）

1. **单因子消融**：`baseline` vs `baseline + 该因子`，四个数据集（scifact / arguana / qbqtc / nq-sub）；
2. **判据**：Δ 同号（C3）且至少两集越过 Δ_min；否则登记为"数据集特定"，不进主线；
3. **不看 test 调参**：阈值/超参只在 train split 上定，test 只读一次；
4. **成本**：索引时间、查询 p50、工件体积三项必须一起报；
5. **可解释性**：每个因子必须能回答"它改变了什么"（词权表 / 扩展词 / 归并对 / 语言），
   不能是"一个黑箱分数"。

## 5. 工程契约

- 每个因子一个工件目录：`data/<dataset>/artifacts/<factor>-<version>/`，
  `manifest.json` 里 `prior_factor` 声明形状/dtype/来源，`network` 声明模型与参数量；
- 因子缺失时外壳必须退化（F1 缺 ⇒ BM25；F2 缺 ⇒ 不扩展；F3 缺 ⇒ 不归并），
  退化路径要有单测；
- 因子之间不共享隐状态，只通过**同一个词表空间**交互；
- 组合顺序固定：归并（F3）→ 索引（F2 编译进倒排）→ 打分（F1/F4）→ 路由（F5/F6 决定用哪套）。

## 6. 阶段计划

| 阶段 | 内容 | 判据 |
|---|---|---|
| **M1** | F1 词权：listwise 蒸馏（复用 §49 的管线，改损失与评估） | 四集同号；scifact ≥ 0.6647 且 CPU 查询编码 ≤ 10ms |
| **M2** | F2 扩展：T5-small 级 doc2query，编译进索引 | 四集同号；miss@10 下降 |
| **M3** | F5+F6：语言路由 + 词典优先的跨语言映射 | 跨语言 ≥ 0.5438（§48 的翻译基线） |
| **M4** | 组合：把通过的因子按固定公式叠加 | 组合结果 ≥ 单因子最好者；不许回退 |

## 7. 不做

- 不训一个大一统模型（§49 的教训：学生容量与目标冲突）；
- 不学融合权重（C1）；
- 不引入"隐式门控"（C2）；
- 不为单数据集调参（C3）。
