# 预注册：基于自适应门控与语义扩散的检索实验 (gated-exp-v1)

- **问题**：现有内核 `concept-v1` 虽能识别词形变体，但无法识别查询中核心词与修饰词的权重差异（筛选），也缺乏对查询缺失词的补全机制（扩散）。
- **两臂对照**：
  - 基线：`bm25`（地板） + `concept-v1`（当前最佳）。
  - 处理组：`gated-exp-v1`（引入 per-token saliency 筛选 + 语义关联扩散）。
- **唯一变量**：检索外壳的打分公式中引入 `saliency_factor` 与 `expansion_factor`。
- **判据**：nDCG@10 增益是否超出噪声带 ($\Delta \ge 0.0143$)；至少有一个子集（Hard Queries）表现出显著提升。
- **预测值**：
  - nDCG@10 提升 0.015 - 0.020；
  - 运行时 CPU 单查询延迟保持在 < 5ms (NQ 规模)。
