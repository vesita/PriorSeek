# 预注册：无参数化逻辑执行外壳 (Parameterless Logic Executor，代号 logic-exec-v1)

## 1. 核心问题与动机

传统检索外壳充斥着大量硬编码的经验超参数（如 BM25 的 $k_1=1.5, b=0.75$，加权系数 $\beta, \gamma, \delta$ 等）。
这导致两个严重缺陷：
1. **外壳过载**：外壳既做物理存储又试图充当调参裁判，调参往往是按下葫芦浮起瓢（短文本有效但在长文本翻车）；
2. **逻辑不可解释**：打分是标量浮点数的加法混合，无法向用户和审计员清晰解释每一个加分和扣分的逻辑因果。

本实验实现**“无参数化逻辑执行外壳 (Parameterless Logic Executor)”**范式：
- **外壳不包含任何超参数**：没有硬编码的权重常数，外壳纯粹作为**物理约束谓词执行器 (Predicate Verification Engine)**；
- **先验逻辑图工件 (`logic-graph-v0`)**：内核将领域常识、显著性判别与拓扑因果关系编译为显式的逻辑约束图：
  - `anchors`：词项核心先验判别力；
  - `coverage_gate`：逻辑完整性门控阈值；
  - `causal_flows`：实体对之间的时序因果与允许距离约束；
- **物理执行与输出**：外壳以纳秒级纯 CPU 遍历文档的证据快照，验证是否满足约束图中的谓词，输出物理透明、绝对可解释的判定得分。

## 2. 实验臂设计（单变量对照）

- **基线臂**：`bm25`（传统经验超参词袋）；
- **主力臂**：`concept-bm25`（外壳包含形态归并）；
- **测试臂**：`logic-exec`（零超参外壳 + 内核逻辑约束图驱动）。

## 3. 核心不变量 (Invariants)

1. **外壳零超参不变量**：外壳代码内部不得包含任何业务硬编码的 magic number（所有饱和度、门控阈值、时序权重均从工件或查询上下文传入）。
2. **全解释性不变量**：每一次打分均可逐项拆解为 `(AnchorScore, CoverageRatio, CausalFlowBonus)` 三大物理分量。
3. **CPU 极速不变量**：在纯 CPU 运行，单查询执行延迟 p50 严格控制在 **< 10ms**。

## 4. 判据与预测

- **判据**：在 $k=10$ 下，nDCG 与 hit@10 保持高水准，且在长短文本之间展现出极高的泛化鲁棒性，彻底摆脱传统超参调优的过拟合陷阱。
