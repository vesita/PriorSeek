# 预注册：各向异性流形白化投影共振算子 (resonance-whitened)

- 日期：2026-11-14
- 目标：验证在离线内核中通过计算语料库 384 维语义空间的均值向量 mu 与协方差矩阵 Sigma，实施奇异值对角白化变换 (Manifold Whitening)，消除高维锥形各向异性背景噪音，能否进一步放大语义相干角动量并提升检索精度。

## 1. 核心理论模型

Transformer 句子表征固有的各向异性退化（Anisotropy）导致任意两个文档的余弦相似度均偏移在 [0.4, 0.6] 的窄带内，微弱的真实语义信号被高维背景直流偏置淹没。

离线内核先验构建：
1. 计算全量语料库 5,183 篇文档向量的中心偏置 mu；
2. 计算协方差矩阵 Sigma = (D - mu)^T (D - mu) / N；
3. 执行 SVD 分解并构建白化变换 W = U * Lambda^(-1/2)；
4. 导出白化先验工件 `whitening-v1/whitening.bin`（384 维均值 + 384x384 变换矩阵）。

外壳共振推演：
内积从原始欧氏点积升级为白化度规内积：
phi_white(d, q) = < normalize((q - mu) * W), normalize((d - mu) * W) >
在更具区分度的白化流形上激发相干共振。

## 2. 实验对照臂

- **基准臂 A**：`resonance` (0.7279)
- **基准臂 B**：`resonance-conjunctive` (0.7283, hit@1 = 62.00%)
- **实验臂**：`resonance-whitened` (白化度规流形共振)

## 3. 判据与预测

- **正向判据**：
  在 SciFact 300 条计分测试集上，观察白化投影是否能够提升高难度长尾样本的区分度，hit@1 维持在 ≥ 62.00%。
- **性能判据**：
  若离线将整个 dense.bin 直接烘焙为白化后向量，在线仅需对 query 做一次矩阵乘法（384x384 在 CPU 上仅需 0.05ms），保持 p50 ≤ 1.2ms。
