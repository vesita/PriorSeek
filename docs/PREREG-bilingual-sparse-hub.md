# 预注册：双语解耦扩散框架 (Bilingual Token Alignment & Language-Specific Diffusion)

## 1. 核心问题与动机

在神经稀疏先验（Learned Sparse Prior）中，如果使用单一的多语言大一统模型在混合词表上直接做语义扩散，会面临严重的**词汇与语法空间交叉污染**：
1. **形态学与语法机制异构**：英文是屈折语，依赖前缀/后缀、时态与复数形态变化；中文是孤立语，依赖词边界切分、汉字组合与虚实词共现。混合词表上的全局注意力往往产生无意义的跨语言杂散权重。
2. **多语言扩散与单语形态的冲突**：如果在单语语境内盲目引入跨语言词汇，会导致词表膨胀与无效稀疏倒排计算。

本实验践行用户提出的架构演进：**分语言做扩散，同一个词在神经网络中的扩散只在同语系下扩散；由多语言 Token 映射层（Bilingual Token Hub）充当跨语言枢纽。**

## 2. 三层解耦框架设计

### 层级一：多语言 Token 映射枢纽 (Bilingual Token Alignment Hub)
- **职责**：在跨语言需求时，负责将 Token（中文或英文）投影到对齐的双语概念空间，输出双语候选 Token 对集合。
- **特性**：只做词汇/概念对齐，不承担语法扩散。

### 层级二：语系特化语义扩散头 (Language-Specific Diffusion Heads)
- **英文特化扩散头 (English Diffusion Head)**：
  - 词表：英文子词词表（BERT/RoBERTa 30k 级）；
  - 扩散机制：在英文句法结构下计算词元非负重要度与形态同义扩展。
- **中文特化扩散头 (Chinese Diffusion Head)**：
  - 词表：中文词元/汉字词表（如 Chinese-BERT / BGE / Qwen）；
  - 扩散机制：结合中文分词（Jieba）与中文上下文注意力，计算中文语义扩充权重。
- **不变量**：每个扩散头严格只在自身语系空间内计算词权，语系之间物理隔离，零交叉干扰。

### 层级三：外壳统一先验倒排 (Unified Shell Execution)
- 离线内核生成规范的先验工件 `sparse.bin`（按语言空间或联合映射空间存储）；
- 外壳保持零超参数的纯 Rust 倒排点积：
  score(q, d) = sum_{t in q intersect d} w(t, q) * w(t, d)
- 线上执行纯 CPU、毫秒/微秒级低延迟。

## 3. 实验臂设计

1. **英文单语对照臂（scifact）**：
   - 地板基线：`bm25`；
   - 英文单语神经稀疏：`learned-sparse`（当前 SOTA 单路）；
2. **中文单语对照臂（qbqtc）**：
   - 地板基线：`bm25`（Jieba 分词）；
   - 中文特化神经稀疏：`learned-sparse-zh`（中文特化内核输出）；
3. **双语跨语言/解耦扩散验证**：
   - 验证多语言 Token 映射枢纽与分语言扩散的解耦有效性与零污染特性。

## 4. 判据与预测

- 判据：在中文检索（qbqtc）上，特化中文神经先验相比传统中文 BM25 获得显著收益；在英文检索上，保持极速低延迟与高精准度。
- 预测：语系特化扩散能有效消除混合词表的语义稀释，外壳依然保持微秒级吞吐。
