# 预注册：稠密向量检索底层性能极致优化 (Dense Performance Optimization，代号 dense-perf-v1)

## 1. 核心问题与动机

目前 `hybrid-rrf` 在 `scifact` 上已经取得了 0.7012 的突破性准确率，但查询端到端延迟为 14.36ms，其中 85% 以上的耗时（约 12ms）发生在单路稠密向量点积上。
分析其物理瓶颈：
1. **点积标量循环未显式展开**：384 维向量采用朴素的 `for i in 0..384` 循环，未充分利用 CPU 寄存器与 FMA 乘加并行；
2. **全量排序内存与搬运开销**：对全量 5,183 篇文档分配连续 `Vec<(usize, f32)>` 并执行 $O(N \log N)$ 排序，而外壳实际只需要 Top-K（如 60）。

本实验实现**“算子级性能极致重构”**：
- **8-way 寄存器并行展开点积**：利用 8 个累加寄存器解开指令级数据依赖，触发 CPU 硬件流水线最大吞吐；
- **有界小顶堆 (Bounded Min-Heap) 快速截断**：仅维护固定容量 $K$ 的最小堆，单次遍历直接过滤掉绝大部分低分文档，时间复杂度降至 $O(N \log K)$，内存零大块分配；
- **核心承诺**：所有的优化纯属物理算子加速，数学打分与排序结果**100% 逐位保持一致（零失真）**。

## 2. 实验臂设计（单变量对照）

- **基线臂**：`dense` (优化前基线，p50 约 12.69ms)；
- **优化臂**：`dense-opt` (SIMD 8-way + Min-Heap，预期压缩至 2~3ms)；
- **融合臂**：`hybrid-rrf` (端到端总延迟从 14.3ms 压缩至 4ms 左右)。

## 3. 核心不变量 (Invariants)

1. **零失真逐位等价性不变量**：点积浮点求和必须在容差内与标量求和严格等价，Top-K 截断结果与全局全量排序完全一致。
2. **零动态重分配不变量**：最小堆容量在检索开始时预先分配为 $K$，遍历过程中只做原地替换，绝不触发堆重分配。
3. **延迟压缩不变量**：单路 `dense` p50 延迟必须压缩至 $\le 4\text{ms}$，`hybrid-rrf` p50 延迟控制在 $\le 6\text{ms}$。

## 4. 判据与预测

- **判据**：在 $k=10$ 下，nDCG@10 保持 **0.7012** 不变，单查询延迟 p50 达到 3.5x 以上的显著加速。
