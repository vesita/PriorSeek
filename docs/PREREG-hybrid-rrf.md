# 预注册：双路无超参 RRF 混合检索 (Hybrid RRF，代号 hybrid-rrf-v1)

## 1. 核心问题与动机

长期以来，搜索实验台上的各路算法始终局限于“单路单模态词法检索（Lexical-only）”的死角中。无论外壳算法或前缀归并如何优化，nDCG 指标始终被锁死在 0.68 以下的单模态物理天花板中。
同级项目 `docseek` 的实测证实：**单路词汇重精准实体、单路向量重宏观语义，两者具有极强的正交互补性，唯有通过双路融合（Hybrid Fusion / RRF）才能消灭召回盲区**。

本实验实现**“双路无超参 RRF 混合检索”**：
- **第一路（词法概念先验路）**：`concept-synonym`（继承词缀屈折归并 + 科学同义概念扩展）；
- **第二路（稠密语义向量路）**：`dense`（利用本地 `all-MiniLM-L6-v2` 离线编码语料为连续二进制 `dense.bin`，线上纯 CPU 极速点积）；
- **无超参 RRF 融合外壳**：
  $$\text{Score}_{\text{RRF}}(d) = \frac{1}{60 + \text{Rank}_{\text{concept}}(d)} + \frac{1}{60 + \text{Rank}_{\text{dense}}(d)}$$
  **外壳不设任何比例权重，没有人工调参的 magic number**，完全依据两路排名的倒数叠加实现自适应互补！

## 2. 实验臂设计（单变量对照）

- **地板臂**：`bm25`（传统词法基准）；
- **单路词法主力臂**：`concept-synonym`（现役最高命中率单路词法）；
- **单路稠密向量臂**：`dense`（纯 CPU 向量点积检索）；
- **双路无超参融合臂**：`hybrid-rrf`（两路 Top-60 候选通过 RRF(60) 融合）。

## 3. 核心不变量 (Invariants)

1. **零在线 GPU 依赖不变量**：文档向量必须全量离线预计算为小端二进制 `dense.bin`，线上检索纯 CPU 运行，查询延迟控制在毫秒级。
2. **零超参数融合不变量**：RRF 公式采用业界标准常数 $k=60$，两路地位完全平等，外壳严禁设置任何业务偏向系数。
3. **隔离性不变量**：向量编码工具只读 `corpus.jsonl` 与 `queries.jsonl`，严禁触碰 `qrels.tsv`（防答案泄漏），工件带有完整的预训练污染声明与 sha256 校验。

## 4. 判据与预测

- **判据**：在 $k=10$ 下，nDCG@10 突破既有单路 0.6801 的天花板，且 hit@10 跃升。
- **预测**：双路互补性生效，nDCG 预计产生实质性跨越（突破至 0.70+），首位命中率与召回率显著提升。
