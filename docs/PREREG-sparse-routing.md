# 预注册：神经编译稀疏索引 (Learned Sparse Lexical Routing，代号 sparse-route-v1)

## 1. 核心问题与动机

传统 Dense 向量检索（如 BGE/ColBERT）虽然能解决同义词和语义泛化，但在线检索需要沉重的向量索引（HNSW），内存开销大且容易发生无边界的语义泛化（把不相关的长文档推高）。
另一方面，传统词法检索（BM25）虽然极快且纯 CPU 运行，但无法在文档中索引它“没写出来”的语义同义词。

本实验探索**“神经编译稀疏索引”范式**：
将深度模型/语料知识图谱的语义理解能力，在**离线索引期“编译”进倒排索引**：
- 为每篇文档赋予 Top-$K$ 个高置信度的**语义增强词项（Document Expansion Tokens）**；
- 这些增强词项直接作为虚拟 Posting 写入 `PositionalIndex`；
- **线上运行时 100% 纯 CPU，零神经网络前向推理**，直接以极速倒排查表享受语义检索红利。

## 2. 实验臂设计（单变量对照）

- **基线臂**：`bm25`（地板，纯原文词法）；
- **概念归并基线**：`concept-bm25`（词法空间形态归并）；
- **测试臂**：`sparse-route`（文档包含原词 + 离线编译的语义高置信增强词）。

## 3. 核心不变量 (Invariants)

1. **零开销不变量**：线上检索必须是纯 CPU 倒排查表，单查询延迟必须维持在毫秒级（NQ 级别 < 10ms），绝不允许在线加载深度模型。
2. **稀疏性约束不变量**：每篇文档的语义增强词数量受严格上限 $K \le 32$ 限制，增强词的虚拟词频不得超过原词的阻尼衰减权重 $\alpha \in [0.1, 0.5]$，防止倒排链爆炸与假阳性泛滥。
3. **退化等价性不变量**：当增强词表为空或 $\alpha=0.0$ 时，行为严格逐位退化为传统 BM25（保持 G1 等价性门）。

## 4. 判据与预测

- **判据**：在 $k=10$ 下，nDCG@10 相比 `bm25` 基线显著提升，且查询延迟 p50 维持在 5ms 以内。
- **预测**：
  - 相比纯 BM25，词汇鸿沟引起的硬漏（Miss Rate）进一步被有效打捞；
  - 检索耗时相比纯 BM25 增加不超过 2 倍，远快于 Dense 向量检索。
