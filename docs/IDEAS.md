# 新思路清单（由 §1–§43 的实验反推）

> 筛选标准：可解释（能用一句话说清为什么）、泛用（同一配置跨数据集）、不拟合标签。
> 每条都给出"观察 → 假设 → 为什么符合标准 → 最小可证伪实验 → 判据"。

## 思路 0（新增，已有实测支持）：因子质量优先于因子整合

§45 的复核显示：同一个"加权倒排求和"外壳，换上 SPLADE 词权后
scifact +3.4pp、arguana **+5.0pp**、qbqtc +0.4pp——三个数据集同号，是唯一通过 C3 的因子。
而所有"轻因子"（概念、邻近、分段单元、DPH）都无法跨数据集复现。

⇒ 项目的重心应从"设计整合公式"转向**因子质量**：外壳保持最小（加权求和），
把力气花在"用什么离线模型产出词权/扩展"。文献里 DeepImpact、doc2query、SPLADE 都是这条路径。

## 思路 1：语料级「因子适用性诊断」（元层面，最优先）

**观察**：同一个概念因子在 scifact 上 +1.4pp、在 arguana 上 −0.1pp（§41）；
同一个段落单元在 arguana 中性、在 scifact −3.4pp（§43）。因子有没有用，看起来由**语料属性**决定。

**假设**：因子增益可以由语料的四个可解释统计量预测：
`形态变体率`（查询词在语料里有共享前缀兄弟的比例）、`OOV 率`、`文档长度中位数`、`df 集中度`。

**为什么符合标准**：判断依据是语料统计，不是标签拟合；结论可写成一句话
（"这个语料 70% 的查询词都有形态兄弟，所以概念归并适用"）。

**实验**：在 scifact / arguana / qbqtc / nq-sub 上各跑一次 `bm25` 与两个因子版，
把"增益"和四个统计量放进同一张表，看是否单调可分。产出 `sl diagnose` 子命令。

**判据**：四个统计量能区分"因子正向 / 非正向"的数据集，且结论在留出的第 4 个数据集上成立。

## 思路 2：证据 × 先验的乘法分离（概率语义）

**观察**：dsh-pod 召回里已经有 `strength`（强度）与 `recency`（时间），但它们是**加性先验**，
和 BM25 相加；scifact 上则完全没有先验项。

**假设**：相关性与先验是两类量——相关性是 `P(q|d)`，先验是 `P(d)`。正确组合是**相乘**
（`score = 证据 × 先验`），先验参数由语义定义（半衰期、来源权重），不需要拟合。

**为什么符合标准**：乘法的语义清楚（先验不能把不相关的文档变相关），参数来自业务定义。

**实验**：在 dsh-pod 的 103 条 recall trace 上，把"强度/时间"从加性改成乘性先验，
比较选中集合与人工标注（需要 50 条标注）的一致性；ps 侧用"文档类型/字段"当先验做对照。

**判据**：乘性先验在标注集上的 precision@k 不低于加性；且在两类语料上方向一致。

## 思路 3：覆盖率作为结构约束（不是权重）

**观察**：BM25 对"只命中一个常见词"的文档仍给正分；§13 的"硬漏"里有一部分是
只匹配到虚词的文档占了前排。

**假设**：对"覆盖查询词比例 < 1/2"的文档，应当排到"覆盖充分"的文档之后——
这是**排序约束**，不是加分系数。

**为什么符合标准**：约束可以用一句话解释（"只命中一个词不算相关"），且没有参数。

**实验**：三数据集上做 `stable sort by (coverage_bucket desc, bm25 desc)`，
桶边界固定为 `1/3`、`2/3`（结构值，不调）。观察 nDCG 与 hit@1。

**判据**：三集 Δ 同号且至少两集越过 Δ_min；若某集显著变差，说明该语料查询词少、约束过强。

## 思路 4：统计单元由「文档长度」决定（可判定的结构选择）

**观察**：§43 段落单元在长文档（arguana，中位 150 词）中性、短文档（scifact，204 词但摘要密集）负；
两者中位长度接近，说明"长度"不是唯一因素，但切分确实丢了文档级词频累积。

**假设**：只有当"文档长度 / 查询长度"超过阈值时，段落单元才划算（长文档里单段证据被摊薄）。

**为什么符合标准**：阈值是结构比值，可由语料统计给出；不是为某个数据集调的魔数。

**实验**：按"文档词数 / 查询词数"分桶，比较同桶内 `bm25` 与 `passage` 的逐查询 Δ；
若"比值大 → 段落更好"单调成立，规则就成立。

**判据**：桶间 Δ 单调；用该规则在 arguana 上跑一次（只在比值大的桶用段落）应优于纯 bm25。

## 优先级

| 顺序 | 思路 | 信息量 | 成本 |
|---|---|---|---|
| 1 | 思路 1（语料诊断） | 高：把"因子为什么失效"变成可解释结论 | 低（只用统计量 + 已有臂） |
| 2 | 思路 3（覆盖率约束） | 中高：零参数、三集可验 | 低 |
| 3 | 思路 2（证据×先验） | 高，但依赖 dsh-pod 标注 | 中 |
| 4 | 思路 4（单元选择） | 中：依赖分桶统计 | 中 |

## 明确不做的（已被数据封板）

- 拟合融合权重 / 用分类器当门（§40）；
- 几何/顺序因子（§12 §38）；
- 参数自由词项模型（DPH/Dirichlet，§38.5）；
- 子词→整词的有损投影（§39.1）。
