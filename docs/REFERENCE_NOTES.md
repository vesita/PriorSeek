## 1. 两个项目各自是什么

## 2. 可以直接借的纪律（已按我们的场景改写）

| 规则 | 出处（flowme） | 我们怎么落 |
|---|---|---|
| **预注册**：跑之前写死「问题 / 两臂 / 唯一变量 / 判据 / 预测值」；事后从多组里挑的机制必须在**没被挑选过的独立出口**再验 | `methodology/PREREG_TEMPLATE.md`、RULES R4 | M2 开跑前先写 `docs/PREREG-M2.md`，test 集只在最后看一次；超参用 train 内部 5 折选 |
| **Δ_min = 2×SE**：没测出差异时必须报 Δ_min，并写「该口径下未测出差异」，不许写「没有效果」 | `measurement.md §3`、`PREREG §3` | 报告里每个学习版结论带 `Δ ± SE` 与 `Δ_min`；单 seed 只报「超过噪声带」 |
| **单 seed 不下定论**；定论只用多 seed 配对 | `measurement.md §8`、R1 | M2 至少 2 seed（不同初始化/数据序），同号才算方向成立 |
| **地板基线**：先跟「免费规则」比（含长度/个数/位置桶等计数类） | RULES R7 | 我们的地板：随机排序、`bm25`、`faq-bm25` 各自作为地板行，Δ 相对它们报 |
| **消融必须 retrain-without**，不是推理时删掉/置零 | RULES R16 | 去掉 seq 特征 = 重训一版（不带该特征），不是把 λ 设 0 后直接比 |
| **干预非零性冒烟**：正式判决前先验证「这个干预真的改了被测量的量」，报 Δ 非零比例 | RULES R29 | 学到权重后先看：有多少查询的 top-10 真的变了；比例过低 ⇒ 该版本作废 |
| **等算力对照**才有归因力 | RULES R30 | 统计基线 vs 学习版：同数据、同特征、同 k；训练算力（步数/时长/GPU）单列 |
| **必要性结论必须在饱和点**；未达饱和只能标「下界」 | RULES R35/R36 | 我们的「训练」是低容量优化：判收敛看 train/valid 损失平台 + 多轮迭代，不用 12k 步门槛（那是它们 LM 的预算） |
| **仪表自检 + 惰性对照**：新通路权重置 0 时，读数必须与旧路径逐位相同 | RULES R28、`PREREG §2 N1` | 我们已有同类强制点：`seq` 在 λ=0 时与 `bm25` 的 recall/MRR/nDCG/MAP 逐位相同（RESULTS §8.2） |
| **跨实现/跨设备复现先逐位对拍，再比自训结果** | nanoSeek README（Python↔Rust `max err=0.00000`） | 我们已有：Rust `seq` 与 Python `ref_score` 在 scifact 300 条上 nDCG 逐查询 0 差 |
| **一个事实一个家**；纪律要写进会自动注入的 `AGENTS.md` | RULES R45/R47 | 本文件只做参考笔记；可执行纪律落 `AGENTS.md`，数字口径落 `STANDARD.md`/`RESULTS.md` |

## 3. nanoSeek 值得学的三件小事

1. **每轮只动一个变量**，并写清「回退判据」（它的 dev-notes 里多次出现「一次改太多变量 → 退化 → 回退」）。
2. **两把尺子验收**：本段的 val + 一把通用尺子（防止只看局部指标自我陶醉）。对我们 = 目标数据集指标 + 一条跨数据集对照（例如中文/英文各留一个）。
3. **状态现场读**：不维护易过期的状态文档，数字从 `run.json`/`results.csv`/日志现读。我们已经在这么做了（`results/<run>/run.json`）。

## 4. 明确不照搬的部分

| 项 | 它们 | 我们 | 原因 |
|---|---|---|---|
| 参数量 | 75M char-level 模型 | 第一步 **3–5 个标量**，上限先定 **≤10k 参数** | 我们训练集只有 scifact 809 条查询 / 300 条测试；75M 参数量比可学习的监督信号大 3–4 个数量级 |
| 训练预算 | 12k 步、每 750 步快照、8GB 显存 | CPU 可训、分钟级 | 我们学的是低容量先验（边权系数/词权），不是语言模型 |
| 任务域 | 语言建模 / 卡片组合 | 检索排序（qrels + 排序指标） | 指标不可微 → 必须用代理损失，且代理≠指标（见 `docs/KERNEL.md` §3 讨论） |
| 框架抽象 | 卡片框架 / MoE 等 | 保持现有 `sl-core` + 适配器结构 | 我们的外壳已经稳定，换内核只换工件 |

## 5. 对 M2（学习版内核）的具体影响

M2 的实验按下面的顺序做，每一步都有可判定产物：

1. **数据**：把 scifact `qrels/train.tsv`（809 条查询）接进规范格式的 train split；其余三个数据集没有 train qrels，
   M2 只能在 scifact 上做有监督，其他数据集只能做无监督/迁移对照。
2. **预注册**：`docs/PREREG-M2.md` 写死：两臂（统计基线 vs 学习权重）、唯一变量、判据（Δ ≥ 2×SE 且 2 seed 同号）、
   预测值（例如「学习版权重会让 order=2 权重趋近 0」）、test 只看一次。
3. **参数预算**：先学 3–5 个标量（λ_seq、order1/order2 权重、距离衰减），再考虑每类边权（数千参数）。
4. **冒烟**：学到的权重必须让 ≥10% 查询的 top-10 改变，否则该口径作废（R29）。
5. **消融**：retrain-without（去掉 seq 特征重训），不是推理时置零（R16）。
6. **报告**：`Δ ± SE`、`Δ_min`、地板行（随机 / `bm25` / `faq-bm25`）、训练算力、CPU 运行延迟、工件哈希。
